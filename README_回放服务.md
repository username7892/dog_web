# 视频回放 Web 服务 - 使用说明

## 一、安装依赖

```bash
pip install flask pymysql opencv-python-headless numpy
```

## 二、启动服务

```bash
cd /home/user/dog_web/python_yoloe
python playback_web.py
```

启动成功后看到：

```
============================================================
  🎥 YOLO 监控视频回放系统
============================================================
  本机访问:  http://localhost:5002
  局域网访问: http://10.21.31.5:5002
============================================================
```

## 三、浏览器访问

在任意设备浏览器中输入：

```
http://10.21.31.5:5002
```

## 四、功能说明

| 功能 | 操作 |
|------|------|
| 选择时间范围 | 点击时间输入框，选择起止时间 |
| 播放 | 点击「▶ 开始播放」按钮 |
| 停止 | 点击「⏹ 停止」或按 Q 键 |
| 倍速 | 下拉框选择 0.5x / 1x / 2x / 4x / 8x |
| 导出MP4 | 点击「⬇ 导出MP4」自动下载视频文件 |
| 空格键 | 暂停/继续 |

## 五、API 接口（供其他系统调用）

### 获取帧数据（JSON）
```
GET /api/frames?start=2026-08-11 16:40:49&end=2026-08-11 16:41:13
```

返回：
```json
{
  "count": 120,
  "fps": 10,
  "frames": [
    {"time": "2026-08-11 16:40:49", "data": "/9j/4AAQ..."},
    ...
  ]
}
```

### 导出视频
```
GET /api/export_mp4?start=2026-08-11 16:40:49&end=2026-08-11 16:41:13&fps=10
```

直接下载 .mp4 文件

## 六、后台运行（生产环境）

```bash
nohup python playback_web.py > playback.log 2>&1 &
```

查看日志：
```bash
tail -f playback.log
```

停止服务：
```bash
pkill -f playback_web.py
```

## 七、常见问题

### Q: 浏览器打不开页面
- 检查防火墙: `sudo ufw allow 5002`
- 检查端口占用: `netstat -tlnp | grep 5002`
- 确认 IP 地址: `ip addr show`

### Q: 页面打开但没画面
- 确认数据库里有对应时间段的帧
- 检查 MySQL 连接配置
- 查看终端报错信息

### Q: 导出 MP4 失败
- 确认 opencv 编译了 ffmpeg 支持
- 检查磁盘空间
